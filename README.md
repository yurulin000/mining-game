# 礦坑遊戲｜GitHub Pages 試玩版

這個資料夾已整理成可直接放在 GitHub Pages 的靜態網站，入口為 `index.html`。遊戲會從 jsDelivr 載入 Three.js，因此遊玩時需要網路連線。

## 發布

1. 在 GitHub 建立一個公開的空白儲存庫，例如 `mining-game`。
2. 將本資料夾內的檔案與子資料夾上傳到儲存庫根目錄（不要只上傳外層資料夾）。
3. 到儲存庫的 **Settings → Pages**，在 **Build and deployment** 選 **Deploy from a branch**，分支選 `main`、資料夾選 `/(root)`，再按 **Save**。
4. 等待部署完成後，試玩網址通常是 `https://你的帳號.github.io/mining-game/`；實際網址以 Pages 頁面顯示為準。

請在公開前確認所有圖片、模型、音樂與音效都有公開發布的使用權。GitHub Pages 網站是公開可存取的。
